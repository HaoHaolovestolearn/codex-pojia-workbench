# 示例：定位 Flask 登录状态异常

目标：成功登录并重定向回首页后，导航栏应显示当前用户昵称；刷新和退出登录后的显示也应正确。

上下文：Flask + Jinja2，用户状态由 session 管理；不要改数据库结构；先检查模板、路由及 session 初始化。日志中的账号和业务数据已经脱敏。

验收：正确密码进入首页显示昵称；刷新保持登录；退出后显示登录入口；错误密码不写入登录 session。

执行：先复现问题，定位根因；做最小必要修改；补充覆盖上述条件的回归检查；运行相关测试并说明结果。不要编造执行记录。

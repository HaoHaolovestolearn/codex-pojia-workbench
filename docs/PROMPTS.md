# 任务模板编写

每个模板保存在 `catalog.json` 的 `recipes` 数组中：

- `id`：稳定、唯一的英文标识。
- `title`：用户能理解的场景名称。
- `category`：筛选时显示的分组。
- `summary`：使用场景与目标。
- `steps`：顺序清楚、可执行且可验证的步骤。

模板不应编造模型身份、替代用户授权、声称解除安全限制或自动获批外部操作。模板质量主要看它能否说明输入、约束、验收条件、验证证据和交付形式。

示例：修复错误时，先写出什么条件触发、原来发生什么、期望发生什么，再给框架、日志、受影响模块和不能改的地方。不要只写“修好它”。

修改模板后运行：`python -m unittest discover -s tests -v`。
